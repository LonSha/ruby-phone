# R25-X8 整机 A/B 对照台 · 证据页

日期：2026-11-18　版本：v4.157.0（未抬版）

## 1. 它是什么

给一段操作序列（就是 `tests/browser/scenarios/*.scen.js` 里的一份场景文件），在两个版本根上
**各跑一遍**，把读数按名字对齐后输出差异清单。它是产品面工具，**不是门禁**：

- 差异多少条都不影响退出码（0）—— 差异是要看的东西，不是红点；
- 只有一种硬错误拒判：两边都零读数 ⇒ exit 2，且不出报告（未执行不得留假证据）；
- 「一边有、一边没」单列 only-a / only-b，绝不压成「相同」；两边都零读数判 unknown。

```
node tools/ab-desk.mjs --a=<旧版本根> --b=<新版本根> \
  --scenes=o1-core-flow.scen.js,o3-media-20.scen.js \
  --out=tests/audit/ab-reports/r25-o3-vs-o2.md
```

输出两件：`*.md`（人看）与 `*.json`（可 diff 的机器面）。

## 2. 跑过的一次（真读数，不是示例）

A=`/tmp/rphead`（205512e，R25-O2 收口）· B=当前树（含 R25-O3）· 视口 390x844 · Chromium 131

| 读数 | 值 |
|---|---|
| 总读数 | 27 |
| same | 17 |
| diff | 1（`o1-core-flow::lock-screen-covers`，锁屏与主屏盒模型差 1px） |
| only-a | 1（`o3-media-20::scenario-threw`：旧版本没有 `config/media-lifetime.js`，动态 import 失败） |
| only-b | 8（R25-O3 的 8 条读数只在 B 侧存在） |
| 结论 | `changed` |

这份报告就是「两版本对拍」要交的东西：同一段序列，旧版本连跑都跑不起来（模块缺失），
新版本 8 条读数全在；而 17 条既有读数逐字相同 —— 说明这次改动没有顺手动到别的面。

### 2.1 同一对版本再跑一次：读数会抖（这是也真读数）

同一对版本（A=`/tmp/rphead`、B=当前树）、同一段序列、默认 `--out`，再跑一次：

| 次数 | 总读数 | same | diff | only-a | only-b |
|---|---|---|---|---|---|
| 第 1 次（`r25-o3-vs-o2.md`） | 27 | 17 | 1 | 1 | 8 |
| 第 2 次（`latest.md`） | 27 | 15 | 3 | 1 | 8 |

多出来的两条 diff 是 `o1-core-flow::app-content-has-box` 与 `::back-button-in-app`：
A 侧两次分别读到 `302x657@86,44` 与 `334x726@51,28` —— **同一个版本自己的两次读数就不一样**，
说明那两条是在过渡动画未收敛时量的（尺寸差 30px 级）。这不是版本差异，是**测量抖动**。

结论（写进台的使用契约）：

1. 台的**职责**是把差异如实列出来，**不替人过滤**（过滤等于在背后改判据）；
2. 差异表里的盒模型 / 坐标类读数**必须人工复核**，报告不得当成「回归证据」直接引用；
3. 想让它更有力：挑**确定性读数**（计数、状态、文本、receipt）作主判据 ——
   `o3-*` 八条就是这种（值全是计数与布尔），所以它们在两次跑里逐字相同；
4. 这也解释了为什么台**不能**当门：它对抖动无免疫力（门靠场景自己的 `waitFor` 收敛，
   而台只负责把两边读数搬回同一张表）。

## 3. 边界（不许读成「全对拍」）

- 它只对拍**读数字符串**：`ok` 翻转、`detail` 变化、一边缺失都算差异，但不解释原因；
- 时间/随机量（如 `perf-*` 毫秒、锁屏盒模型 1px）会如实报成 diff，**要不要忽略由人决定**——
  台不替人过滤（过滤等于悄悄改判据）；
- 它不替代浏览器门：门的结构自证、读数下限、失败冻结仍在 `tests/browser/gate.mjs` 与
  `scripts/browser-gate-run.mjs` 里。

## 4. 判据

`tests/r25_x8_ab_desk.test.mjs`（8 项全绿）：

- X8-1 内核 5 条边界；X8-2 同源对照全 same；X8-3 四档不压平（缺的一边显式 `missing`）；
- X8-4 两边零读数 ⇒ `unknown`；
- X8-5 **负控制**：把 `only-a` 抄成 `same` ⇒ X8-3 同款断言必红；
- X8-6 「台不是门」：源码里只许 exit 0/2（不许出现 exit 1），缺参数当场 exit 2；
- X8-7 表结构不被 detail 里的换行 / 竖线打散（一条读数只占一行，每行恰好 5 个竖线）；
- X8-8 自检有**产品端消费点**：`--self-check` 真跑一次打出 5/5 与四档档名
  （原先只有测试引用 ⇒ 被零消费导出门禁判红，这是它被接线的理由）。

## 5. 自检（台自己坏没坏）

```
node tools/ab-desk.mjs --self-check
```

打内核五条边界与四档档名。自检不成立 ⇒ exit 2（这台此刻给不出可信对照，未做任何比对），
与「用法错误」同一语义；任何情况下都不出现 exit 1 —— 台的退出码里**没有「判失败」这一档**。
