## 二、主要不足

### RubyPhone
1. **样式层失控**：4030 个 `!important`，1312 种颜色，61 种 z-index。改一个 app 的样式经常要再加 `!important` 压过上一层，越改越难改。
2. **设计 token 不完整**：已有 238 个 `--` 变量，但 app 层大多直接写 `#94a3b8`、`#64748b` 等 slate 色值（前 4 种就占了近 400 处），本质上是同一套灰阶反复硬编码。
3. **app 视觉不统一**：honey、wangxiang、poker 等 app 各有一套独立的 CSS（单个 2k～4.6k 行），按钮、卡片、列表、弹层各写各的。
4. **反馈组件缺失**：133 处原生 `alert/confirm`。在手机壳内弹浏览器原生对话框会打断沉浸感，也无法区分成功、警告、错误。
5. **无障碍不足**：1701 个按钮中大量是纯 emoji/图标按钮，没有 `aria-label`；还有 43 处可点击的 `div`。
6. **主题能力弱**：没有系统暗色适配；`prefers-reduced-motion` 只有一处兜底。
7. **单文件过大**：phone.css 22.5k 行，加载、维护和定位都困难。

### 记忆插件
1. **设置面板过深**：4 个标签页加 4.7k 行的 settings-ui.js，常用项和高级项混在一起。v3.423 已经把 API 连接前置，但"高级"页仍然非常长。
2. **内联样式**：333 处 `style="`，常见的是 `padding`、`color:var(--ls-warn)`、提示文字的字号和颜色，应该收编为工具类（如 `.ls-hint-warn`、`.ls-stack-sm`）。
3. **无障碍**：标签页没有 tab 语义，抽取节奏切换用的是 `div role=button`，键盘无法触达（**本次已修**）。
4. **原生对话框**：23 处 `alert/confirm`，与黑曜石主题割裂。
5. **只有一套暗色主题，响应式只有 1 处 `@media`**：窄屏依赖 `overflow-wrap` 兜底。

## 三、重构方案（按收益/风险排序，分期执行）

### U1 · 基础层：统一 token 与层级刻度（两项目共用规范）
- 定义共享语义 token：`--surface-0..4`、`--text-1..4`、`--accent`、`--success/warn/danger`、`--radius-xs..xl`、`--space-1..8`、`--font-xs..xl`。
- 定义 z-index 刻度：`--z-base/raised/dropdown/sheet/modal/toast/max`，替换 61 种散值。
- 编写 codemod：把 slate 灰阶（`#94a3b8`、`#64748b`、`#cbd5e1`、`#e2e8f0`……）机械替换为 token。这一步预计可消掉约 40% 的硬编码色值。
- 新增静态门：新代码禁止增加 `!important`、硬编码色值和裸 z-index（只比较增量，存量逐步消化）。

### U2 · 组件层：一套通用基础组件
- `PhoneDialog` / `PhoneConfirm` / `PhoneToast`，替换 RubyPhone 的 133 处和插件的 23 处原生对话框。异步 Promise 接口兼容原有调用点。
- `IconButton`（强制提供 `aria-label`）、`ListItem`、`Card`、`Sheet`、`Tabs`（复用本次插件里的 WAI-ARIA tabs 模式）。

### U3 · RubyPhone 分 app 迁移
- 迁移顺序：高频的微信、日历、日记、设置 → 中频 → 游戏类。
- 每个 app 拆出独立 CSS，去掉 `!important`，改用 token 和组件；phone.css 只保留外壳与全局层。
- 加入暗色主题：token 加 `[data-theme=dark]` 一套值；`prefers-reduced-motion` 覆盖所有动画。

### U4 · 记忆插件信息架构
- 设置面板改为"常用 / 故事 / 记录 / 高级"四层。高级页按主题折叠分组，加入搜索框以快速定位配置项。
- 333 处内联样式收编为工具类。
- 加入窄屏断点（≤480px 单列、标签页可横向滚动）。

## 四、本轮已落地
- **记忆插件**（分支 `ui-a11y-settings`）：
  - 设置面板标签页补齐 `tablist/tab/tabpanel` 语义，以及 `aria-selected` 与 roving tabindex。
  - 支持方向键、Home、End 切换标签。
  - 设置页和主页卡片两组抽取节奏切换，从 `div role=button` 改为真实 `button`，放在 `radiogroup` 中并同步 `aria-checked`。
  - 补充 `:focus-visible` 焦点环。
  - 新增测试（位于 lonsha-memory-plugin 仓库）`ui_a11y_settings_tabs.test.mjs`。6 个既有 UI 测试文件（73 项）加新测试全部通过。
