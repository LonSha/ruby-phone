# 📱 RubyPhone (终极虚拟智能手机) / ruby-phone

> **三方集大成的酒馆全功能拟真移动终端系统**  
> 深度融合 **yuzuki-phone**（原生物理手势视图栈 + 双轨大模型通信） + **瑟瑟小手机**（小红书瀑布流 + 百度贴吧盖楼 + 舆论风闻） + **色色灵感状态栏**（458 条精选玩法按需瞬时注入 + 666 条全量成就簿 + 实时 HUD）。  
> **彻底切断外部数据库依赖，全原生即装即用！**

---

## 🌟 核心革新：彻底告别外部数据库 (Zero-Database Architecture)

传统的小手机与灵感状态栏插件强依赖 `AutoCardUpdaterAPI` (ACU SQLite 数据库) 与几万条的外部大数据库模板，没装插件直接弹窗报错瘫痪，换卡/换分支极易数据串味。

**RubyPhone 采用彻底的原生解耦方案：**
1. **内置静态化资产**：
   - 458 条精选玩法数据（体位 239、多人体位 53、侍奉 77、场景 34、附加玩法 55）全量内置为轻量静态 JSON（11KB）。
   - 666 条全量纯净成就库（功能 212、隐藏 167、剧情 91、养成 78、收集 53、纪事 41、称号 24）全量内置为轻量静态 JSON（200KB）。
   - **零网络请求、零外部数据库依赖，开箱即用！**
2. **原生会话沙箱持久化**：
   - 微信聊天、小红书笔记、贴吧发帖、已选玩法、已解锁成就状态全部存入当前聊天的 `SillyTavern.getContext().chatMetadata['st_virtual_phone']`。
   - 随聊天记录自动保存，换会话自动隔离防串味，导出聊天记录永久保留进度！
3. **瞬时世界书与 Prompt 动态注入**：
   - 在灵感工坊勾选玩法后，自动在发送请求时动态挂载到系统深度，生成结束后根据开关**一键自动清空**，零污染长线上下文！

* **落账层 `config/system-notifications.js`**：过去通知只有「瞬时横幅 + 队列防刷屏」，一闪即逝、错过即永久丢失。`NotificationLog` 在展示的同时把每条通知写入环形历史（`sys_notifs`，上限 200 条），**同 senderKey 3 分钟内合并为一条并累加 ×N**，且合并不重置已读状态。
* **落盘策略**：800ms 防抖写入 + `flushNow()` 兜底；`_normalize` 对脏数据净化（非对象跳过、缺 id 补号、按时间倒序、环形裁剪）；全部失败路径返回 `{error}` 且**绝不抛异常**——落账失败只丢历史，不阻断通知展示。
* **三入口**：顶部下拉 / 锁屏速览 / 桌面图标。
* **交互**：按 App 筛选 chips（带计数、按数量排序）、关键词搜索、未读高亮、×N 合并计数、单条删除、一键全部已读 / 清空，点击结果跳回原 App；时间按「今天 HH:MM / 昨天 HH:MM / M/D HH:MM」智能显示。

### 🔎 全局搜索 (Global Search)
* **检索内核 `apps/memory/global-search-engine.js`**：17 个来源统一索引 —— 微信会话（含联系人）、朋友圈、日记、短信、通话、织光机收藏册、日历备忘、音乐歌单、世界脉搏、微博热搜与推荐帖、记忆长期层、阅读书架、成就、小红书、贴吧、通知历史（注入 `chatContext` 时另含酒馆正文楼层）。
* **评分模型**：标题全等 +100 / 前缀 +80 / 包含 +60 / 仅正文 +30，并按命中位置与文本长度加权；命中片段居中开窗高亮（先转义再拼 `<mark>`）。
* **容错**：每源独立 `try/catch`，坏源不影响整体，并上报 `lastErrors`；不在场的数据源自动跳过。

### 🎛️ 控制中心 (Control Center)
* **免打扰**：真实拦截横幅（通知仍入账不丢），状态随会话隔离。
* **Wi-Fi**：开关联动状态栏图标。
* **手电筒**：点亮手机壳暖光晕。
* **显示缩放**：滑块 80–120%，复用设置页同一套 `--phone-shell-*` 通路，新键 `sys_shell_scale` 优先、旧键 `phone-shell-scale` 回落，两处双向一致。
* **立即锁屏** + **音乐卡**（上一首 / 播放暂停 / 下一首，真实操作 `MusicData`）。
* **状态隔离**：`sys_notifs` / `sys_dnd` / `sys_shell_scale` / `sys_flashlight` / `sys_wifi` 全部随会话隔离，换角色不会把上一角色的系统状态带过去。

### 🔒 锁屏速览层
* 时段问候（夜深了 / 早上好 / 上午好 / 中午好 / 下午好 / 晚上好）、最近 5 条未读通知速览（轻点解锁并直达通知中心）、正在播放音乐条。
* 全部能力**可选缺失降级**：通知层或音乐层不存在时自动回到原锁屏。

* **按单一真源纪律修法**：不往两条路径各补一次手抄调用（那正是 v2.23~v2.55 反复漏改的形态），而是给该 App 补 `onChatChanged` 并接入 `ST_PHONE_REBIND_APP_KEYS`，三路自动覆盖；同时把换会话路径里原有的显式调用收敛掉，消除第二条真相与重复执行。
