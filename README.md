# 📱 RubyPhone (终极虚拟智能手机) / ruby-phone

> **三方集大成的酒馆全功能拟真移动终端系统**  
> 深度融合 **yuzuki-phone**（原生物理手势视图栈 + 双轨大模型通信） + **瑟瑟小手机**（小红书瀑布流 + 百度贴吧盖楼 + 舆论风闻） + **色色灵感状态栏**（458 条精选玩法按需瞬时注入 + 666 条全量成就簿 + 实时 HUD）。  
> **彻底切断外部数据库依赖，全原生即装即用！**

---

## 🌟 核心革新：彻底告别外部数据库 (Zero-Database Architecture)

传统的小手机与灵感状态栏插件强依赖 `AutoCardUpdaterAPI` (ACU SQLite 数据库) 与几万条的外部大数据库模板，没装插件直接弹窗报错瘫痪，换卡/换分支极易数据串味。

**RubyPhone 采用彻底的原生解耦方案：**
1. **内置静态化资产**：
   - 458 条精选玩法数据（体位 239、多人体位 53、侍奉 77、场景 34、附加玩法 55）全量内置为轻量静态 JSON（11KB）。
   - 666 条全量纯净成就库（功能 212、隐藏 167、剧情 91、养成 78、收集 53、纪事 41、称号 24）全量内置为轻量静态 JSON（200KB）。
   - **零网络请求、零外部数据库依赖，开箱即用！**
2. **原生会话沙箱持久化**：
   - 微信聊天、小红书笔记、贴吧发帖、已选玩法、已解锁成就状态全部存入当前聊天的 `SillyTavern.getContext().chatMetadata['st_virtual_phone']`。
   - 随聊天记录自动保存，换会话自动隔离防串味，导出聊天记录永久保留进度！
3. **瞬时世界书与 Prompt 动态注入**：
   - 在灵感工坊勾选玩法后，自动在发送请求时动态挂载到系统深度，生成结束后根据开关**一键自动清空**，零污染长线上下文！

## 📲 应用全景矩阵 (App Ecosystem)

### 🔮 灵感工坊 (Playbook) —— [源自 色色灵感状态栏，重构脱离数据库]
* **458 种玩法体位分类索引**：支持体位、多人体位、侍奉、场景、附加玩法分类切换与关键词即时检索。
* **多选胶囊与状态记忆**：点击标签即时勾选，已选项呈现霓虹微光高亮。
* **发后自清机制**：勾选“发后自清”后，当 AI 回复生成完成，自动清空已选标签，告别生硬死记。

### 🏆 成就簿 (Achievement) —— [源自 色色灵感状态栏，重构脱离数据库]
* **666 条全量成就树**：包含功能、养成、剧情、收集、纪事、称号与 167 条未解之谜隐藏成就！
* **全卡达成率仪表盘**：动态统计已达成项与百分比进度条。
* **专属趣评展示**：达成成就即可查阅作者撰写的精辟、毒舌又充满情趣的专属评语。
* **全屏悬浮解锁横幅**：达成瞬间弹出类似主机平台（Xbox/PlayStation）的金色奖杯通知横幅！

### 📕 小红书 (XHS / RED) —— [源自 瑟瑟小手机]
* **标志性双列瀑布流**：高仿小红书现代卡片流，支持封面图、点赞数、作者头像与话题标签。
* **笔记详情弹层**：大图预览、沉浸阅读、楼中楼评论区与即时互动。
* **用户发布笔记**：可在手机端直接发布图文笔记，分享日常生活。
* **AI 动态捕获**：大模型可在回复中输出 `<RED>` 或 `<xhs>` 标签，自动生成角色的小红书日常。

### 💬 百度贴吧 (Tieba) —— [源自 瑟瑟小手机]
* **贴吧广场**：支持进吧切换（江城生活吧、弱智吧、青石大学吧等）。
* **主帖与楼中楼盖楼**：1 楼楼主大字排版，2 楼到 N 楼热烈神评回帖。
* **用户自主发帖**：选择贴吧，发布新帖，参与社区讨论。
* **AI 动态捕获**：大模型可在回复中输出 `<Tieba>` 标签，自动发帖盖楼。

### 💬 微信 (WeChat) —— [源自 yuzuki-phone]
* **拟真社交**：支持单聊、群聊、转账、发红包、联系人动态生成。
* **音视频通话**：拟真来电弹窗，支持接入 MiniMax / OpenAI 等 TTS 语音连播。
* **朋友圈**：角色自动发动态，支持点赞与楼中楼评论互动。

### 👁️‍🗨️ 微博 (Weibo) —— [源自 yuzuki-phone]
* 实时剧情热搜榜单，带有高仿微博信息流与 IP 属地，支持一键转发微信。

### 🎵 网易云音乐 (Music) —— [源自 yuzuki-phone]
* 全局毛玻璃悬浮微型播放器，支持剧情推荐真实歌曲即时播放。

### 📔 日记本 (Diary) —— [源自 yuzuki-phone]
* 根据聊天记录，AI 自动以角色第一人称视角撰写精美排版的实体书日记。

## 🕹️ 原生物理手势与体验

* **微信/iOS 级边缘右滑返回**：全手势接管，任意界面从屏幕左侧向右轻滑即可丝滑退回上一层。
* **物理双层视图栈**：拒绝简陋的 `display: none`，采用真实 Z-index 堆叠，返回绝不白屏闪烁。
* **原生防 Base64 膨胀引擎**：所有上传的图片自动落盘酒馆 `/backgrounds`，只存路径，聊天存档永不臃肿！

## 💡 安装方法 (Installation)

### 推荐：通过 SillyTavern 扩展管理器直接安装
1. 打开 SillyTavern，进入“扩展”面板。
2. 点击“安装扩展”，在 Git 仓库输入框中粘贴：
   `https://github.com/LonSha/ruby-phone.git`
3. 点击安装，完成后刷新酒馆页面。
4. 在顶部导航栏即可看到「📱」手机入口图标！

### 手动安装
将本项目文件夹重命名为 `ruby-phone`，完整放入：  
`SillyTavern/public/scripts/extensions/third-party/ruby-phone/`  
重启 SillyTavern 即可生效。
