# Agent Note: 番茄钟切页与计时生命周期分开

Status: implemented

## Problem

计时、任务、统计和设置在一屏里争用滚动空间。创建任务时倒计时可能结束，控制器的刷新此时不能擦掉输入。

## Decision

页面选择只存在于 FocusView；切页隐藏非当前页面，不销毁表单，也不触发 App 的 deactivate。计时、任务列表和统计分别更新；每秒 tick 只更新可见的时间文字。存档格式不变。

## Alternatives considered

只挂载当前页面可以减少隐藏 DOM，但需要复制并恢复任务名、模式、时长、光标和输入法状态。四个页面只有一份任务列表和两个小表单，不值得引入第二套表单状态。

## Consequences

开始任务会回到专注页，编辑中的倒计时结束不会强制跳页。表单只在当前挂载期保留，不承诺重开 App 后恢复。`tests/browser/scenarios/focus-v4.scen.js` 用真实 interval、控件焦点与短屏滚动验证这个边界。

## 宿主验收
SillyTavern 1.19.0 的未分层抽屉规则会覆盖 `rp.legacy`：1000×900 窗口内手机抽屉仅高 100px，「创建任务」位于 y=-175。只在 `#phone-panel.drawer-content.phone-panel-open` 上恢复既有视口变量，避免改动关闭态和酒馆自身的抽屉。修复后，在独立数据目录由聊天命令打开手机，从应用库点击番茄钟：1000×900 和 390×844 触屏模拟均能建任务、开始、暂停、恢复、切四页、保留草稿；任务底栏实测 48px 且中心命中。这里没有把触屏模拟当作真机输入法验收。
