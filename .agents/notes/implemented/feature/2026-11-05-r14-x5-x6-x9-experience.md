# Agent Note: R14 时光信封、经历包与分批审阅
Status: implemented

## Problem
织光机缺少延期解封的保存快照，分享面缺少逐项审阅的经历包，离线清单缺少逐条处理状态与重开游标。

## Decision
时光信封挂织光机，使用会话键 tw_envelopes_v1，保存显式选中素材的文字快照，以无冲突且可解析的剧情日期判断解封；无钟封存。支持延期与撤回，来源删除后标明保存时快照。经历包挂备份分享面，复用 sharing-boundary 对单一接收人预览，只导出扁平勾选文字，不遍历嵌套引用，不回填上游。离线分批审阅沿 AwayMode owner 保存逐条状态及应用分组/批次游标；去处理仅打开原应用，不执行通知动作。写入口使用会话栅栏。

## Alternatives considered
用现实日期解封会在剧情停滞时提前暴露正文，因此拒绝。复制完整源对象会泄露嵌套秘密，因此只投影白名单文字字段。新增离线副账本会产生两个事实源，因此在原状态键内扩展。保存后立即同步回读不能覆盖异步存储，审阅和游标改为等待存储 Promise 再回读。

## Consequences
八项定向测试、Chromium十二条读数、518条键登记通过。信封支持剧情日期与创建后发生的明确事项完成条件，取消事项不解封；照片只有说明快照。经历包支持本地导出及明确缺失附件提示，作品仅标题，接收端按声明接收人预览与确认，逐字段净化并对同内容去重；声明不是加密认证，真实授权元数据仍需进一步核对。离线页支持分批与逐条状态，但未覆盖真实宿主并发和失败恢复；不得声明本期完成。未执行全量回归。
