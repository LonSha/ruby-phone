# Agent Note: R14-X8 实况来源与查看基线

Status: implemented

## Problem
事务台只持事务阶段与引用，缺少用户选定来源在上次查看后的变化对比。

## Decision
事务台事件实况提供显式选择日历、旅行和共同事项来源、刷新、标记已看和删除实况。来源保持原 owner，只读其会话存储；实况键 affairs_live_v1 保存引用与摘要指纹，禁止保存正文快照。相同来源 ID 的修改显示已修改，消失显示来源失效，坏来源显示读不出来。查看基线只有用户标记已看时推进。

## Alternatives considered
保存原始 JSON 可精确比较，但会复制源正文并扩大存储，因此采用长度与两路非加密指纹；它只用于变化提示，不用于身份认证或安全裁决。后台监听可即时更新，但当前选择显式刷新和页面重开，避免新增生命周期监听。

## Consequences
四项定向测试与 Chromium 八条读数通过；键归属审计通过。当前三类来源已接入，另接入作品小说和已由微信 owner 加载的有效回复指纹；未加载回复明确不可用，不调用会产生迁移写入的 getMessages，不能将这部分实现宣称完整 X8。指纹有理论碰撞概率；内容不作事实写回。真实宿主尚未验证，页面写入使用 session-gate；创建核对当前记录避免旧列表覆盖。
