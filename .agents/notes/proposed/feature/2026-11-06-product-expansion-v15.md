# Agent Note: RubyPhone 第十五期拓展创新计划
Status: proposed
## Problem
第十四期和具身在场统一桥（v4.125.0）交付后，虚拟手机已具备物理现场感知 HUD、现场面对面防偷窥拦截与删楼回退能力。然而，虚拟手机作为生活与世界互动的媒介，仍缺乏近场 NFC / 面对面互传、群聊多人协同工作台、锁屏情境联动壁纸、嘈杂环境情境通话、朋友圈精细分组互动、以及主屏情境小组件（Smart Widgets）等深层沉浸媒介体验。本计划以 2026-11-06 本地源码（v4.125.0）为基线展开。

## Proposal
将手机媒介交互能力落实为完整产品闭环：严禁纯内核单跑，必须实现数据Owner、控制器、UI 视图、跨 App 路由、桥接与定向验证套件的全链路垂直贯通。与优化提升九项共 18 项，两仓共 36 项。

### R15-X1 · 具身近场通信（NFC/面对面名片与快传）
- **现有底座与差距**：桥接层具备在场感知，但在同场面对面时，两端手机缺乏专属的近场互联媒介（如手机碰一碰交换名片、面对面近场直传照片）。
- **本期交付**：构建虚拟 NFC 近场通信协议（`PhoneNearFieldRadar`），同场角色在场时触发碰一碰声效与名片交换卡片，支持免流量即时传输随身档案或相册图片。
- **玩家入口**：控制中心「NFC 碰一碰 / 隔空投送」磁贴与面对面快传面板。
- **验收旅程**：在同室场景下激活近场雷达，扫描出同场活跃角色并发出名片交换，对方即时接收并在联系人中归档；非同场时禁用。
- **实施规模**：L，包含近场探测状态机、传输事务、控制中心 UI 及定向断言。

### R15-X2 · 群聊多人实时协同工作台（行程/经费 AA/拼单记账）
- **现有底座与差距**：群聊仅具备单调文本交流，缺乏多人参与的结构化协作应用（如集体聚会后的 AA 记账本、旅行日程协同编辑清单）。
- **本期交付**：在微信群聊中集成群协同工作台（`GroupWorkbench`），支持发起群经费记账、多人分摊计算与协同备忘录，实时展示各角色确认状态。
- **玩家入口**：群聊输入区「+」号拓展面板「群协作工作台」。
- **验收旅程**：在群内发起 AA 账单，系统根据群成员自动拆分金额，各角色在剧情进展中逐一标记结算，总账与余额实时更新。
- **实施规模**：L，包含协同状态账本、群插件挂接、群聊卡片渲染及测试套件。

### R15-X3 · 锁屏动态壁纸与个性签名根据剧情因果联动
- **现有底座与差距**：手机壁纸与签名仅为静态资产，未与 LonSha 记忆端的天气（晴/雨/暴雪）、重大剧情事件或角色心情建立因果动态映射。
- **本期交付**：实现情境动态壁纸引擎，根据当前时间段、天气状态或角色重大关系突破，自适应切换锁屏视觉主题与个性签名台词。
- **玩家入口**：手机「设置」→「个性化与情境壁纸」。
- **验收旅程**：当剧情进入雨夜场景时，锁屏壁纸自动切换为雨滴玻璃主题，签名变更为角色此时的深沉心境；晴天后自适应复原。
- **实施规模**：L，包含情境规则匹配器、壁纸主题状态机、锁屏视图及定向测试。

### R15-X4 · 沉浸式情境通话（根据现场嘈杂度叠加环境声效）
- **现有底座与差距**：通话界面仅有普通头像与计时器，无法反映通话发起方或接收方所处物理环境的真实氛围（如背景风暴声、闹市喧嚣、列车轰鸣）。
- **本期交付**：构建通话环境情境模拟器，根据双方所处场景的物理标签，在通话界面动态呈现「环境声背景条」，并注入带有语境杂音格式的字幕对白。
- **玩家入口**：电话 App 通话中界面情境指示条。
- **验收旅程**：在暴风雪山道接听来电，通话界面出现风雪呼啸动画与环境声标签，对话字幕带有 `[呼啸风声]...喂...听得清吗？` 拟真修饰。
- **实施规模**：L，包含声学语境映射、通话视图拓展、CSS 动效及端到端断言。

### R15-X5 · 朋友圈动态的分组可见、隐秘点赞与跨角色互动网络
- **现有底座与差距**：朋友圈动态仅为单一线性流，缺乏真实社交网络的分组可见（仅某人可见/不给某人看）、以及角色之间互相点赞评论的二级互动网。
- **本期交付**：重构朋友圈社交网络，支持发布动态时设置可见范围，在后台编排非在场角色对动态的延迟点赞与针对性互动留言。
- **玩家入口**：朋友圈发布页「可见范围」与动态详情互动区。
- **验收旅程**：发一条仅特定角色可见的动态，其他角色不产生阅读与点赞；特定角色在下一时段发表专属评论并触发手机通知。
- **实施规模**：L，包含社交权限矩阵、角色互动调度器、朋友圈 UI 及测试断言。

### R15-X6 · 戏剧性突发状况（电量告急/信号盲区倒逼面对面）
- **现有底座与差距**：手机始终处于电量充足、满格信号的理想状态，缺乏为剧情制造戏剧冲突的设备物理限制机制。
- **本期交付**：引入手机物理限制突发事件模拟器，在特定张力情节触发「电量低至 1%」自动关机倒计时，或进入「地下深处/绝壁无信号」状态，倒逼剧情切换。
- **玩家入口**：状态栏低电量警告与无服务网络标识。
- **验收旅程**：紧急剧情触发信号阻断，所有远程通讯被拦截并提示「无服务」，直到走出盲区或接通备用卫星电台；电量耗尽前触发最后一通未完电话。
- **实施规模**：L，包含设备状态机、通讯熔断逻辑、状态栏渲染及破坏负控制。

### R15-X7 · 角色专属桌面主题定制与个性化提示音文案
- **现有底座与差距**：手机 UI 主题风格单一，缺乏不同伴侣或重要角色为玩家手机定制专属图标风格、字体颜色与个性化提示语的能力。
- **本期交付**：构建角色主题包引擎（`ThemePackEngine`），支持随好感度提升或剧情赠礼解锁角色专属主题包（定制应用图标、专属气泡颜色与按键提示文案）。
- **玩家入口**：手机「主题商店」角色专属陈列区。
- **验收旅程**：应用某角色的专属主题包后，桌面图标转为对应风格配色，微信发送按键文字变为专属昵称，并可在设置中自由切换。
- **实施规模**：L，包含主题包协议、CSS 变量热插拔、主题商城 UI 及定向测试。

### R15-X8 · 随身数字遗物探索（加密备忘录草稿解密与旧档案）
- **现有底座与差距**：备忘录仅记录当前文字，缺乏旧周目或故去角色遗留在手机芯片里的加密草稿、未发送的邮件与隐藏日记等“数字遗物”。
- **本期交付**：实现数字遗物加密档案柜，在特定剧情阶段以破损数据块或加密笔记形式呈现，玩家可通过线索拼凑密码解锁阅读隐藏故事。
- **玩家入口**：备忘录 / 文件保险箱「加密归档」专区。
- **验收旅程**：发现带有密码锁的旧备忘录，输入剧情中获得的纪念日密码解密成功，解锁一段尘封往事日记与相关插图线索。
- **实施规模**：L，包含解密状态机、加密数据块格式、备忘录 UI 扩展及定向测试。

### R15-X9 · 主屏情境小组件（Smart Widgets，根据现场快照呈现卡片）
- **现有底座与差距**：主屏幕缺乏支持即时信息聚合的卡片小组件，无法直观呈现 LonSha 传来的 L0 现场位置、在场羁绊、当日待办与倒计时。
- **本期交付**：构建桌面情境小组件系统（`SmartWidgets`），支持在主屏放置「当前场景快照」、「同场在场卡片」与「今日重点日程」三种动态磁贴。
- **玩家入口**：主屏幕负一屏 / 桌面编辑添加小组件面板。
- **验收旅程**：在桌面添加「现场感知小组件」，实时显示当前地点、天气与身旁在场人员；点击小组件直接深链跳转至对应 App 详情。
- **实施规模**：L，包含组件宿主容器、数据桥接订阅、桌面排版 UI 及测试套件。
