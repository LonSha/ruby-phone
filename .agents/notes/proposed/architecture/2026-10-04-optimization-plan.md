# Agent Note: RubyPhone 优化提升计划（v3.56.0 核实基线）

Status: proposed

## Problem

RubyPhone 已有足够的功能体量，下一阶段的主要损失来自运行时缺陷、功能入口不完整和跨 App 行为不一致。继续只增加文件与静态判据，收益会被用户实际操作中的空白页、卡顿、陈旧结果和串会话抵消。

本计划根据代码与定向实测制定；本轮仅交付规划，不实施、不抬版、不声称当前全量通过。事实起点为 2026-10-04 的 v3.56.0，HEAD `ac0a570`，起手工作区干净：入口 885412 字节 / 14142 行，200 个 `*.test.mjs`，80 个 App 目录。`apps/memory/` 同时承载记忆与图谱，消费矩阵实际为 **81 个 App**，不能把目录数当 App 数。

## Proposal

近期先兑现用户可见正确性，再改善热路径与维护成本；拆文件只在减少重复接线或缩小故障影响范围时进行。以下 O1–O8 是建议任务，不代表已交付。

### O1 · 浏览器与宿主操作回归（P0，规模 L）

依据：v3.56.0 修复返回按钮缺席，记忆插件 v3.271.0 修复设置页空白，均说明静态存在性检查无法证明入口可用。`docs/runtime-verification-boundary.md` 仍将无浏览器写成长期结论；本轮工具浏览器实测为 Chromium 124，120×40px 元素获得真实布局尺寸。

工作：保留零依赖 Node 门；增加独立浏览器运行层，先覆盖桌面分页、打开 App、返回、锁屏、设置保存、搜索取消、切会话、清当前数据、重开面板。App 首屏采用空态与有数据两组，按真实 APPS 表枚举 81 个入口，具体交互优先覆盖微信、健康、记忆、搜索、诊断、记账。用真实 DOM 与生产 CSS 取可见性、点击、滚动、焦点、控件可达性。再在真实 SillyTavern 中验证宿主事件、持久化与双扩展共装。

验收：320/390/768/1280px 视口完成核心流程；入口存在但被遮挡、宽度为零、按钮没绑定、保存后重开丢失均能转红；证据带版本、浏览器、fixture/host 区别。独立浏览器没有宿主接口时，只结论布局与模块交互。环境缺能力必须报未执行，不能计通过。

依赖：各入口可在独立浏览器中装载；宿主批次还需可访问的测试 SillyTavern。本轮只探测了浏览器能力，没有跑过两个完整插件的真实宿主流程。

### O2 · 全历史搜索真正让出事件循环（P0，规模 M）

依据：`GlobalSearchEngine.searchAll()` 虽按 2000 条循环分组，函数没有异步让出；控制器 `Promise.resolve().then()` 仅推迟开始。本轮 10000 条实测同步返回、全部扫描，零延迟取消计时器在返回时尚未执行。耗时单次约 147–244ms，只是本机合成读数，不是手机性能承诺。

工作：索引构建、命中评分、结果收束均纳入可中断任务；片间让出宏任务或帧，保留代际取消。源适配器若先同步物化全数组，必须计入耗时并改为可分批取数，否则扫描异步仍会被建索引卡住。`scopeSummary()` 不得每次重复全历史 build。优先协作式分批，实测仍不达标再评估 Worker。

验收：1000/5000/10000 楼和 60000 条上限下，计时器/点击可在完成前执行；中途取消确实少扫描；换词、改楼、换会话均不提交旧结果；无取消时结果与现同步基线一致；进度与截断覆盖真实。记录最大片耗时与取消延迟，先建立目标设备基线再定阈值。

### O3 · 数值边界与知情口径补漏（P0，规模 S–M）

依据：`LonShaBridge.onFloorCommitted(null/' '/[]/false)` 中空白族会经 `Number()` 变成第 0 楼并调用 `invalidateFloorAt(1)`；本轮明确复现 null、空串、空数组、false。`onFloorRollback` 已有严格入口门。`socialguard.normalizePost` 把 seenBy 的 null/[]/false 收为 0，`readingsOf` 数出这些键，互动门却判未看过；样本四个键中三项无效，界面统计 4，允许互动仅 1。

工作：commit 与 rollback 使用相同楼层取值口径，保留合法数字 0；知情值只认能表示已看的有效记录，历史 0 与脏值走显式迁移/丢弃读数，禁止凭键存在给未知者补“已看”。扩大 weak-coercion 门对条件表达式、包装器与边界调用的覆盖，以语义探针辅助文本扫描。

验收：没给楼层不失效、不计入 ingest；0 仍失效第 1 楼之后。seenCount、historySummary、firstView 与 mayInteractWith 对同一记录一致；归一重放幂等，未知不获互动权。负控制必须破坏生产入口并重跑同款行为判据。

### O4 · 会话切换与异步回信一起失效（P0/P1，规模 L）

依据：已交付 lifecycle 表与三条清理路径，但表内有名字只证明接线；生图、搜索、微信生成、总结等回信可能晚于会话切换。需在已有代际栅栏上核对所有写入口，而不是从零重建 lifecycle。

工作：统一核查 chat/branch/revision 身份与在飞任务；切聊、删楼、重生成、清数据后，旧任务只结束自己的资源，不能写当前会话。重开面板重点观察监听器、计时器、对象 URL 与调用重试；页面前后台切换后重取当前状态。

验收：A 发请求→切 B→A 回信、A 清空→旧保存回调、删楼→旧召回返回、反复开关 20 次等序列均可重现；B 状态逐字不受影响，监听器回到基线，旧响应有可读拒绝原因。先审计实际缺口，已有门已守住的路径不重复施工。

### O5 · 写入成功与真实落盘一致（P1，规模 M）

依据：案头 App 的写包装存在多种返回口径，常见 `ok:true` 与 `saved:false` 并存；纯函数处理成功、存储提交成功、重开可回读是三个不同阶段。

工作：以 PhoneStorage 实际契约为准统一关键写回执；失败保留草稿与旧有效值。对多键操作记录完成范围，明确恢复/补偿入口；渲染时不以写入副作用修复数据。审计对象值与 JSON 文本混用的历史兼容路径。

验收：set 返回 false/抛错、get 抛错/回旧值、多键中途失败时均不显示“已保存”；重开往返可验证；清除一个 App 不连坐其他桶；不新增另一套数据库。

### O6 · 入口接线瘦身与重复实现治理（P1，规模 L）

依据：入口仍 885KB，旧“移植六刀瘦身”方向有效，但直接搬记忆插件 barrel 模式会扩大逐字副本与兼容退路负担。

工作：按真调用图挑最值钱的聚簇：懒加载映射、生命周期表、更新说明数据、跨 App 注入装配。先移纯数据，再移无状态装配；每次保持 App 加载顺序、单例、旧键和异常退路。大健康/微信视图按性能与职责再分诊。

验收：每刀有净减少的重复接线或可解释的加载收益；同名函数取对实现；动态路径、缺席退路与方法名同源；新增模块进入现有扫描面；真实开 App/切聊流程不变。入口行数只作附属读数，不设新的任意数字目标。

### O7 · 渲染性能按热路径治理（P1，规模 M–L）

依据：已有 boot-timing、perf_probe、内存趋势探针；“从零加性能监测”是重复建议。当前能力还不足以证明浏览器里大列表滚动流畅。

工作：用 O1 浏览器测首屏、面板重开、长列表、搜索与健康仪表；按证据实施分页/窗口化、合并 DOM 更新、源版本缓存和非关键懒加载。优先移除非必要动画与粒子；后台降频与恢复后重取一起设计。性能读数被动采样、有界保存，避免守护器自身常驻拖累。

验收：典型和极端数据都有 before/after；保留选择态、滚动位置、键盘焦点；复开资源不增长；不将 Node 拼串耗时写成浏览器帧耗时。目标设备读数未获时，保留证据缺口。

### O8 · 计划、基线与测试成本收口（P1，规模 M）

依据：PLAN 的现行优先级仍写第 1 层“完成 3/10”、反向桥上游未交付，均与代码/同文件交付段冲突；gate-budget 仍以 v3.23.1 为基线，长期超预算已失去回归辨别力。

工作：当前计划与历史交付台账分开；当前基线由脚本生成，保留测量版本、设备与时间。门禁按变更选择定向集合，完整回归仍按既有收口纪律执行；耗时基线按规模归一并保留历史，禁止通过重刷阈值掩盖退化。处理干净检出依赖 `.sourcematerial` 的现有用例：公开夹具验机制，私有真素材验保真，两组状态分报。

验收：新会话能识别已完成项与本次待办；未知不报 0，未执行不报通过；干净检出基础门可复现；真实素材缺席有明确理由；测试优化不减少关键负控制与运行时覆盖。

## Alternatives considered

继续批量增加 App 的强项是覆盖更多玩法，当前 81 件已有规模且 32 件只接生命周期，新增目录会继续扩大孤立入口，故后于现有任务联动。一次性将全仓改成统一架构能减少形式差异，但历史夹具和加载契约影响过大，采用按聚簇切分。全搜索直接迁 Worker 能隔离 CPU，但源取数依赖宿主对象与主线程存储，先修可中断取数和扫描，再凭性能决定。

## Acceptance criteria

推荐三批大更新：第一批完成 O1 核心流程、O2、O3、O4 高风险边界；第二批完成 O5、O6 与 O7 实测热点；第三批完成 O8 与扩展计划的首批联动。交付以用户操作结果与对应证据为准，不能以测试文件数或 App 数增量代替。

本计划与[拓展计划](../feature/2026-10-04-expansion-plan.md)互链。实施时每批读取当前 HEAD 重算基线，已被别的版本完成的条目直接转完成，禁止按本文件快照重复做。

## Risks

浏览器工具可用不等于目标手机或宿主可用；独立页面只能证明其覆盖面。异步搜索会改变返回类型，须同时迁移控制器、进度与历史测试。跨会话栅栏不能只靠 UI 抹结果，必须拦真实写入口。旧素材不一定允许进入公开夹具，不能为可复现性直接上传源内容。
