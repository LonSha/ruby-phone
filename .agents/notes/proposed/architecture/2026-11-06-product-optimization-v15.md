# Agent Note: RubyPhone 第十五期优化提升计划
Status: proposed
## Problem
第十四期和具身在场统一桥（v4.125.0）交付后，虚拟手机已具备物理现场感知 HUD、现场面对面防偷窥拦截与删楼回退能力。然而，手机媒介在多任务栈悬浮恢复、全局聚合搜索深度穿透、跨 App 富文本流转、万条聊天记录虚拟滚动切片渲染、以及同室防偷窥隐私模式精细管控上，仍存在显著的真实交互断点。本计划以 2026-11-06 本地源码（v4.125.0）为基线展开。

## Proposal
将手机媒介交互能力落实为完整产品闭环：严禁纯内核单跑，必须实现数据Owner、控制器、UI 视图、跨 App 路由、桥接与定向验证套件的全链路垂直贯通。与拓展创新九项共 18 项，两仓共 36 项。

### R15-O1 · 桌面多任务栈与后台 App 原位悬浮恢复
- **现有底座与差距**：App 切换通常直接卸载或重置前台视图，缺乏统一的多任务挂起栈（`task_stack`），切出后再切回导致滚动条位置丢失、未提交表单被清空。
- **本期交付**：实现桌面多任务栈管理器，后台保留各 App 的瞬时 DOM 滚动位、表单输入草稿与状态树，切回时原位悬浮毫秒级恢复。
- **玩家入口**：底部手势条/多任务切换卡片流。
- **验收旅程**：在微信编写长消息中途切到浏览器查资料，再切回微信，输入框草稿与键盘焦点完好无损；内存警戒时安全序列化挂起。
- **实施规模**：L，包含多任务调度器、视图挂起/恢复契约、CSS 动效及定向测试。

### R15-O2 · 全局聚合搜索的模糊拼音匹配与跨 App 深度穿透
- **现有底座与差距**：全局搜索仅支持字面量包含匹配，缺少拼音首字母模糊匹配，且搜索结果无法一键直接穿透并定位到原 App 内部具体楼层或条目。
- **本期交付**：引入拼音与模糊分词索引，支持短信、备忘录、通讯录、动态等多 App 数据的全局聚合检索，点击结果精准深链直达并高亮目标项。
- **玩家入口**：桌面下拉全局搜索栏。
- **验收旅程**：输入拼音缩写精准命中联系人与聊天关键词；点击搜索条目直接唤起微信并自动滚动至对应聊天气泡。
- **实施规模**：L，包含模糊检索算法、跨 App 深链路由、高亮渲染及定向测试。

### R15-O3 · 跨 App 富文本、截图与媒体附件的标准流转分享链路
- **现有底座与差距**：备忘录笔记、聊天图片、文件保险箱附件在各 App 之间数据格式割裂，缺少标准的 Intent / 分享协议，无法一键跨 App 转发流转。
- **本期交付**：构建标准跨 App 媒体共享中心（`ShareSheet`），支持将备忘录富文本导出为长图发送至聊天、聊天图片一键保存至相册或设为壁纸。
- **玩家入口**：各 App 详情页「分享」按钮与系统分享面板。
- **验收旅程**：在备忘录选中图文点击分享，选择微信联系人，自动将富文本与图片组装为聊天草稿并在会话中发送成功。
- **实施规模**：L，包含分享中枢协议、媒体适配器、分享弹窗 UI 及端到端断言。

### R15-O4 · 虚拟输入法角色专属口癖联想与长篇草稿掉电保护
- **现有底座与差距**：虚拟键盘仅具备通用输入，缺乏根据当前对话角色的口癖、亲密度自适应弹出个性化词语联想，且长文本草稿缺乏自动持久化守护。
- **本期交付**：构建个性化输入法预测联想引擎与草稿自动守护器，输入时自动推荐角色专属口吻短语，草稿按毫秒级防抖写入持久化缓存。
- **玩家入口**：聊天界面输入法键盘候选词栏与草稿恢复提示。
- **验收旅程**：面对傲娇角色时候选词自适应弹出匹配文风短语；输入中途强行刷新页面，再次进入聊天输入框自动复原草稿。
- **实施规模**：L，包含联想词库算子、草稿持久化存储、输入法 UI 及定向测试。

### R15-O5 · 离线通知与延期到达消息的剧情时间序自动重排
- **现有底座与差距**：手机处于剧情关机、无信号或离开场景期间，系统积压的通知在开机后直接瞬间全部弹出，缺乏符合剧情真实时间戳的平滑铺展与重排。
- **本期交付**：实现时序通知流水线，关机或离线期间的事件按故事发生真实时刻打上时间戳，开机时按时间轴有序汇入通知中心，避免瞬间刷屏。
- **玩家入口**：锁屏与下拉通知中心。
- **验收旅程**：角色剧情离线 3 天，开机后通知中心按「前天」、「昨天」、「刚才」分段呈现错过的事件，不覆盖已有正常通知。
- **实施规模**：L，包含通知时序队列、时间分段聚合器、通知中心 UI 及测试套件。

### R15-O6 · 手机整机镜像打包备份与跨周目存档继承
- **现有底座与差距**：缺少手机专属整机配置（壁纸、安装应用布局、联系人备注、备忘录）的导出备份与继承机制，开启新周目时全部被动重置。
- **本期交付**：提供手机整机镜像备份与恢复管理器（`PhoneBackupManager`），支持打包全量手机状态为独立快照包，新周目一键选择继承。
- **玩家入口**：手机「设置」→「系统备份与云端还原」。
- **验收旅程**：一键打包当前手机配置并导出，在全新存档中导入备份包，桌面壁纸、铃声设置、微信历史与备忘录完整恢复。
- **实施规模**：L，包含备份序列化协议、差异恢复检查、设置 UI 及破坏负控制。

### R15-O7 · 超长聊天记录虚拟滚动与切片加载
- **现有底座与差距**：单会话消息超过数千条时，DOM 节点全量挂载导致手机界面滑动剧烈掉帧，内存占用飙升。
- **本期交付**：重构聊天视图滚动管线为虚拟切片渲染（Virtual List），仅保留视口内及上下缓冲区的 DOM 节点，动态复用节点高度并保持滚动锚点。
- **玩家入口**：微信 / 短信长聊天会话界面。
- **验收旅程**：在加载万级消息历史的测试会话中，上下飞速拖动滚动条帧率稳定在 60fps，不白屏、滚动位置不漂移，内存占用稳定。
- **实施规模**：L，包含虚拟滚动算法、动态高度测量池、视图重构及压测套件。

### R15-O8 · 快捷指令与多 App 自动化链式任务宏
- **现有底座与差距**：玩家操作多 App 需频繁手动跳转，缺乏由条件触发或一键执行的链式工作流自动化能力。
- **本期交付**：构建手机快捷指令引擎（`PhoneShortcuts`），支持玩家定义或一键运行「晚安模式」（设闹钟 + 发微信晚安 + 开免打扰）等链式宏命令。
- **玩家入口**：负一屏 / 快捷指令 App 工作台。
- **验收旅程**：点击「晚安」快捷卡片，系统依次调起闹钟设置、微信自动发送消息并切换手机至勿扰模式，回执如实汇总。
- **实施规模**：L，包含指令执行器、跨 App 动作管道、快捷指令 UI 及测试断言。

### R15-O9 · 现场同室面对面防偷窥隐私模式精细管控
- **现有底座与差距**：v4.125.0 实现了面对面通讯拦截，但在同室有其他角色在场时，手机界面仍完全明文暴露私密信息，缺乏防偷窥隐私伪装面。
- **本期交付**：联动 LonSha 记忆端的在场角色名单，当检测到敏感角色同室在场时，自动激活「防偷窥隐私模式」，支持私密相册加密隐藏、通知正文模糊遮罩及一键伪装锁屏。
- **玩家入口**：状态栏隐私盾牌指示器与控制中心隐私开关。
- **验收旅程**：当目标角色进入同一房间时，状态栏亮起隐私防护，通知内容自动变为「收到一条新消息（防窥隐藏）」；远离后自动解锁还原。
- **实施规模**：L，包含在场感知状态机、UI 隐私过滤器、视图伪装层及定向测试。
