# 占位:下列条目由 tools/bump_v4060.py 写入 ITERATION_LOG.md 与本版 update-log 条目
- 【本版治的是**一处判据对撞**,不是一条普通缺陷:第十一道门的 R3 与 v3190 的 A1 在「零消费面」上不可能同时满足】上游 lonsha-memory-plugin 在其 v3.323.0 交付 C 包三项(人物关系轨迹与因果链与视角卡)时,向它的跨仓外供登记表新增了三面 relationHistory 与 causalChain 与 perspectiveCard,consumer 一律如实写 none@0(下游本仓一个都不消费)。冻读取按 R9 口径显式刷新后,第十一道门立刻报六处:R3 三处点名这三面「本仓没有任何登记行带 upstreamFace 指向它」,R8 三处点名「理由台账里没有它的非空理由」。补上理由后 R8 转绿,而 R3 仍红 —— 因为原实现只认**一种**归属,即 registry 登记行。
- 【另一条路会撞上另一条判据:两条判据在这一点上互斥】给这三面各补一条登记行(原实现的唯一通关方式)会撞上 tests/system-v3190.test.mjs 的 A1:它硬断言每一条登记行的 consumers 长度至少为一,而这三面的消费者数是零 —— 报出来就是「登记了没人用」。本仓另有明令「禁止为让接口有消费而加调用」与「禁止为了让门变绿而削判据」。于是两条判据在「零消费面」上不可能同时满足:一条要每面都有登记行,另一条要每条登记行都有人用。
- 【为什么是改 R3 而不是改 A1 或伪造消费:**产品级假读数在那里**】该数组的语义(其模块注释自述)是「上游产出、本仓消费」的消费侧登记面;更要紧的是 config/capability-health.js 的 minUpstreamOf 从它派生「插件最低可用版本」,取该 owner 名下所有带 since 的面的最大 since。把三面(上游版本 v3.323.0)塞进去,就会把用户看到的「插件最低可用版本」门限从 3.322.0 抬到 3.323.0 —— 对装了足够新版插件的用户**虚报「你的版本偏低」**,指使去升级一个并不需要升的版本。那正是本仓反复治过的那类错读数。A1 守的正是这条语义,它是对的;错位的是只认一种归属的那一侧。
- 【正解:归属有两种合法形态,原实现只认第一种属语义错位】本仓对「上游一面」的回应本就有两种:一是**在用**(registry 里有一条带 upstreamFace 指向它),二是**不用且说明为什么**(未消费理由台账 tests/audit/upstream_face_unconsumed.json 里有一条非空理由)。两种都算「有归属」,都没有才是这一向要抓的沉默。修法:R3 判定面从「只有 row」改成「row 或 有理由条目」,并在门脚本头部与判据本体处各写一段长注留档对撞的修前实测与不选另两条路的理由。R8 原样不动(它管的仍是「如实登记未消费的理由」)。上游自己的台账 docs/planning/X_SERIES_LEDGER.md 的 M-X9 跨仓影响节早逐字预告过这条通路:该行声明 none@0 就必须在理由台账里给出非空理由。
- 【本版自己抓到的两处自伤,合并前已修,留痕】一,首版的理由取数口只有一个「非空」问法,于是理由为空时 R3 与 R8 会同时报同一个缺失 —— 那正是本仓治过的「同一件事两份口径」。修法:拆成两格问法,R3 只问存在性(hasUnconsumedEntry:台账里有没有这一面),理由的成色一律交 R8,并加判据钉住「条目在场但理由为空时 R3 必须不报」。二,首版新套件的 runGate 固定跑真仓的门禁脚本,于是凡改过门禁文件的负控制其实跑的还是原件 —— 破坏根本没生效,那正是本仓记过的「负控制对原件断言」假绿形态。修法:runGate 优先跑夹具里那一份。
- 【新套件与负控制:改的是判据,所以负控制必须打在判据自己身上】tests/system-v4060.test.mjs 十二例:A 形态二例(自述已改口径且旧口径与旧报错文句都已清掉;R3 本体真合上了存在性取数口且取数口只一处实现),B 行为五例(无行无条目即点名;补上理由条目即不再点名且转绿;条目在场而理由为空时归 R8 不归 R3;真仓裸跑绿且面数与问题数逐格如实;未破坏的副本树必须绿),C 负控制二例(真源码定点破坏:一例把存在性取数口改成恒真从而抓不住幽灵面,一例把台账取数口改成恒假从而有理由条目也被读成没归属;两例都配了原版上同款判据必真的反向对照),D 分工钉子二例(两份口径已分流且两处自述都写明同一条分工;台账是真读数不是占位符 —— 每条理由必须点名对应的产品项编号),E 版本锚一例(下限形)。断言一律用 includes 而非正则:本套件锚点里全是括号与星号,正则转义层数一多判据自身会静默失效 —— 首版 B1 就因星号转义退化成「反斜杠重复零次」而侥幸通过,属假绿,已改掉。
