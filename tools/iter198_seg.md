## 迭代 198 · v4.39.0（2026-02-09）

- 【版本升至 4.39.0（五源同源）：第五期 R5-X4 传闻源头图与证词回溯】溯源图（`config/provenance-graph.js`，R-X2 已交付）能回答「这条从哪来、上游还在不在、被谁撤了」；`retellChains`（context-compose）也会把「同一传闻三平台转述」归成一条链。但**手机侧零消费**：全仓零 `independent` / `corroborat` 命中。于是「一条消息被转了三次」与「三个目击者各说了一遍」在界面上**完全同形** —— 而这两件事处置相反（前者仍是孤证、后者才算互相印证）。计划原文点名要治的正是这半句：**「热度高」与「独立来源多」是不同结果**。
- 【契约件新增六态：没有面 / 没有可回溯来源 / 孤证 / 互相印证 / 有争议 / 读不到】压平任意两态都会造出处置相反的处境长得一样。其中「没有溯源面」与「这一条没有可回溯来源」最容易被压成一格：前者是「读不到从哪来」，后者是「确实没记来源」。
- 【转述不算独立来源（本项核心口径）】只认 `witness` / `document` 两类；`retell` 一律不算（它按定义就是别人的话又说了一遍）；`unknown` 也不算（上游没标 ⇒ 判不了，**不硬算一条**）。且**同一 `rootKey` 下的多条只算一条**——同一件事的两种说法不是两个来源。
- 【反证独立成态且优先呈现】有明确反证 ⇒ `disputed`，且反证行**排在最前**（那是用户最该先看的一格）。「有争议」与「互相印证」必须不同句。
- 【被撤回的源不消失】撤回了就如实列出「曾经有过，现在失效」，不许从清单里悄悄拿掉（那会让用户以为从没人说过）。
- 【不产任何可信度分数】计划原文两条不做：不重复实现舆论热度、不给人物贴骗子标签 —— 故设 `RUMOR_FORBIDDEN_KEYS` 并在自检里**真跑**一次深度扫描。
- 【控制器 rumorFaceOf（取数走上游，降级不撒谎）】上游 `rumorSources`（M5-X4，本版未实现）不在场时按计划原文落**纯本地降级**：只有本机可见的同群同文转发痕迹能算「转述」，**独立来源一律判不了**（不硬算）—— 同一段话在本机出现两次，只证明「这句话被说了两次」，证明不了「有两个人各自知道这件事」。
- 【视图消息菜单「来自哪里」+ 面板】只在文本/图片这类「可以是被转述的内容」上给；面板分列独立来源数 / 转述数 / 未标注数 / 反证数 / 已撤回数，**没有证据链时一条线都不画**。
- 【与上一版的接续：R5-X2 的「两格分列」纪律 + R5-X1 的「不硬算」形态】计划原文写的是「现有社媒事件/来源定位/记忆证词页 + M5-X4」——本版把它真正复用起来，不是另起一套：「独立来源 vs 转述」与 R5-X2 目标树的「计划 vs 事实」同规（**两格分列**：合成一格就答不了用户真正要问的那一问）；而「未标注来源不算独立」与 R5-X1 的「草稿不是事实」同规（**判不了就不硬算**）。R5-X2 那两处形态（唯一出处、不硬算）在本版各有一处同族落点（`corroborationLineOf` 唯一出处、`unknown` 不进独立计数）。
- 【本版自己抓到的四处判据缺陷】① C1~C4 首跑全红：`ChatView` 构造期要 `Audio`、`WechatApp` 构造期要 `document`，Node 里都没有 ⇒ **夹具缺件**（改为按真原型建实例）；② C5 判据判全文，而 `'single'` 在 18888 行的既有 chat-view 里别处也出现 ⇒ 改为只判本版新增的那一段；③ D1 首版改 `RETELL` 那一条时去重仍在 ⇒ 独立计数不变，**红得落点不对**（与 R5-X1 的 D5 同族）；④ D5 镜像缺 `apps/settings` 与 `apps/app-injection.js` 及其依赖 ⇒ 副本 import 直接 ERR_MODULE_NOT_FOUND，那是「因缺文件而红」而不是「因破坏而红」（改为整棵 apps 树拷过去）。
- 【判据 tests/system-v4390.test.mjs 二十一条】六组：口径（六态互不同形、独立来源唯一出处、纯契约零副作用、视图接线）/ 内核行为（三次转发呈一个根仍是孤证、同根不同类别仍算一条、未标注不算独立、反证优先、被撤回不消失、三态三句不同）/ 接线行为（上游在场 / 上游不在场只给转述 / 取数抛了 / 同文不同人不升格 / 视图不直摸上游）/ 五条定点破坏负控制（各带原版必真的反向对照）/ 版本锚。
- 【不做：不重复实现舆论热度】本件不产任何热度 / 分数读数（`RUMOR_FORBIDDEN_KEYS` 自检真跑）。
- 【不做：不给人物贴骗子标签】本件只判「来源是几条、是不是独立」，**不判谁说谎** —— 故读数里没有可信度、没有说谎者名单。
- 【不做：没有证据链就不画线】来源行只列**真实存在**的来源；只有名字相同或关键词相同**不算**连线（本件不产任何凭相似度猜出来的边）。
- 【看起来没坏但显示不对】本版四处缺陷都不报错、不崩界面，只是「夹具缺件」「既有字符串被算成本版缺陷」「破坏落点不对」「镜像缺文件」。
- 【运行时验证边界】本版未做浏览器/真宿主取证。「沿边回到原消息」属**真 DOM 层**读数（点击 + 渲染 + 跳转），归浏览器门；本版判的是它的可判定前件（来源行带得出 ref、跳转声明沿用既有 `pgJumpOf`，本版不另造跳转）。docs/runtime-verification-boundary.md 的当版实测数字由 tools/refresh_doc_readings.py 现场跑两道门写入。
