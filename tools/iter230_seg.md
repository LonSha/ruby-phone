- 【R11-X8 做了什么】电池动力学 / 蜂窝弱网 / 健康手环三个内核早在 R10 就写好、也被中枢实例化过，但产品端全仓零 import。本版新建 config/device-face-bridge.js（277 行纯映射层），把三域读数接成产品面：状态栏电量与信号格、锁屏电量整句、健康 App 心率曲线、设置页设备读数块。三域分别是 battery / signal / band，元信息与归因词表都收在桥接层里，产品端只消费不另写一份。
- 【三条真缺陷一次治掉：两个真源 / 声明了却零写入 / 读不到就编一个】① 状态栏原本读宿主的 navigator.getBattery，与虚拟手机自己 tick 出来的电量是两个真源（剧情里手机放电到 5，状态栏还显示宿主笔记本的 100）；② 手环的 historyLog 从声明至今全库零写入，也没被 _save 带走，「心率曲线」在手机里从来没存在过；③ 锁屏读不到回落 78，构造期电量假值 85，模板预写假读数 —— 78 不是用户电量也不是缺数据，是编出来的一个看起来正常的读数。三条都是同一族谎报形态：显示了一个没人测量过的数字。
- 【三态不同形：计划点名的纪律落地】读不到（missing）/ 读取失败（threw）/ 正常（ok）是三件不同的事，不许粉饰成同一句话。桥接层把它们分档：ok 给数字与折线，weak（0 格但读数正常）变色不动透明度，missing 与 threw 都只给短横线而绝不带旧值，且两档文案分开（数据缺失 / 读取失败）。无服务与读不到必须分两句 —— 把后者说成前者等于把系统坏了粉饰成你在地下室，剧情上会骗到人。
- 【弱网可见：0 格与 1 格在 DOM 上真的看得出不同】信号格数走 data-bars 属性（同时也是无障碍改进：读屏念得出几格），CSS 侧弱档是变色 #e6a23c 而不是降透明到看不见 —— 弱网态本来就该显眼，降透明是把这个状态藏起来。未知态另有自己的选择器（灰格 + 半透明 + 斜纹），三档互不同形。
- 【曲线可回溯：≥10 点、按时间升序、随盘走】bandSeriesOf 先按时间升序排再判点数，enough 为 count 大于等于 HEALTH_SERIES_MIN（10）；historyLog 补了唯一写入口 sample(now) 并进了 _save 与 _load（恢复时 slice 裁剪到 BAND_HISTORY_MAX 240）。生理变动之后自动采样（modulateBiometricsByEvent 末尾自己调 sample），不靠谁记得手动记一笔。点数不足与一次没采到分两句：刚戴上不是手环没在跑。
- 【本版自己抓到：DOM 桩不解析 HTML，「画出来才看得见」的效果在无头夹具里无处落脚】首跑 C1 报信号格必须有 5 格可点亮但实测 1 不等于 5。根因不是实现：五个格子是模板字符串里的静态片段，而 DOM 替身按文件头自述不解析 HTML 也不做命中测试，querySelectorAll 只会按 innerHTML 里 class 出现次数造空壳。修法两层：实现侧补 data-bars 属性（真正的好处是无障碍），判据侧改读属性，并补第四档断言（中枢换桩之后格数必须回落 0，不许停在上一拍的 1 格）。
- 【本版自己抓到：判据自己算错域数】首跑 F3 报 2 不等于 1 —— 信号 missing 加曲线 empty 两域都不是 ok，汇总应报 1/3 域可读而我只期望 1 个坏域。这是判据自身的偏差，不是被测对象的错。修后补两条：一域坏不许把另一域读数带没（电量仍要如实给 50），三域全坏必须说都没读到（不是一切正常）。
- 【本版自己抓到：负控制写成两句不同，等于没打中分辨力点】首跑 G2 报破坏后同款判据必须转红但实测仍绿。根因是原谓词只断言无服务与读不到两句文案不同，而破坏把读取失败与数据缺失合并成同一句时两句仍然不同（一是真无服务，一是破坏后的假无服务），破坏没打中分辨力点。修法新增纯谓词 unknownNotBlamedOnSignal，直接断言读不到那一档的文案本身必须含数据缺失且含不是无服务。教训：负控制要打中判据的分辨力点，不是随便找个不等就够。
- 【本版自己抓到：判据抛错会让夹具挂死，表象是跑不完而不是一条红了】首跑套件被外部超时 SIGTERM，输出只有 Terminated。根因是壳在 createInPanel 里挂了一个 30 秒时钟轮询，某条判据在 try 块中间抛错时 shell.destroy() 永远走不到，进程被 interval 钉住。修法：installShellHost 加回收登记表 track(shell)，restore() 里逐个 destroy 且收尾失败不掩盖原错。判据红不该让门禁挂死 —— 挂死时先试 --test-force-exit 才看得到红在哪。
