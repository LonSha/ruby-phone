- **【A7 新模块 · config/submodel-isolation.js】** 副模型隔离面的单一真源：静默面（`quiet` / `skip_save`）、上下文面（`include_world_info` / `include_jailbreak` / `include_character_card` / `include_names`）、空载面（`images` / `stop` / `stop_sequence`）与 `buildSubmodelParams` / `judgeSubmodelIsolation` / `isolationLine`。
- **【A7 三态互不同形】** `isolated`（就绪）/ `missing`（**没写**：某一项根本不在参数里，处置是「不知道会不会触发」）/ `leaky`（**写了但方向错**：`quiet: false`、`include_world_info: true` 之流，明确会触发）。把 `missing` 并进 `leaky`，诊断页答不出「是漏写了还是写反了」；把 `leaky` 并进 `missing`，「写反了」会被当成「还没写」而永远等不到人修。
- **【A7 接线】** `config/api-manager.js` 的 `_callTavernGenerateRawFallback` 不再就地手写十个隔离字面量：参数由真源构造，且**造完即自检** —— 非就绪时留一行 `isolationLine` 读数到控制台（不阻断请求：隔离面坏了也不该让日记生成整个失败）。
- **【A7 度量面而非形态面】** 隔离正确性此前只写在注释里，删掉任意一行不会有任何东西响，而后果是**读数方向被改变**（副模型开始回答被注入进去的设定，输出依旧工整、读数面上看不出来）。本版把它变成可点名的三态 + 可回读的一行读数。
