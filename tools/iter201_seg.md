## 迭代 201 · v4.42.0（2026-03-23）

- 【版本升至 4.42.0（五源同源）：第五期 R5-X9 跨书专题夹与带来源的研究成稿】阅读侧已有单书全文找句（`searchBookChunks`）、摘录/批注与研究清单。但手机侧全仓零 `dossier` / `专题` 命中：摘录只能挂在**一本书**下面（`excerpt.bookId`），没有任何一格能表达「这一篇论证跨了哪几本」。于是「三本书同名人物」在界面上**无法区分**（都叫同一个名字）—— 而那正是验收原文点名要治的第一条。
- 【契约件新增面四态 × 引用五态 × 三栏】面：还没有这个专题 / 有专题但没引任何段落 / 有可回源的引用 / 读不到。引用：可回源 / **改版需重新核对** / **书没了（失效）** / 无版本需确认 / 读不到。三栏：**原句** / **我的解释** / **反证**。
- 【★ 同名不同书不混引（本项验收第一条）】书目**按书 ID 去重**，绝不按书名合并 —— 同名两本书是两本。判据 D5 锁住它（破坏成按书名去重 ⇒ 三本书同名人物被合成一本）。
- 【★ 批注不伪装原文】摘录的 `text` 进原句栏、`annotation` 进解释栏 —— 合成一格就等于把我写的话当成书里原文（验收原文点名禁止）。判据 D4 锁住它。
- 【★ 失效照旧列出，不静默丢】书被删 ⇒ `gone`；书改版（指纹变了）⇒ `stale`；没记版本 ⇒ `unpinned`；书在但正文读不到 ⇒ `unreadable`（**不是**「可回源」）。四态互不相同，且**都在清单里照旧列出**。
- 【★ 未选择的资料不进成稿】导出只认用户勾过的引用（计划原文「不做：不全库上传」）。一条都没得导时**拦住**，且理由与「读不到」不同形。判据 D1 锁住它。
- 【导出带书名 / 章节 / 版本 / 定位】四样齐全，成稿才回得到原处（验收原文点名）。
- 【不产任何自动结论】计划原文「不自动认定研究结论为剧情事实」—— 故设 `DOSSIER_FORBIDDEN_KEYS` 并在自检里**真跑**一次深度扫描。
- 【控制器九口】`dossierRefs` / `dossierSelected` / `dossierToggle` / `dossierClearSelection` / `bookMapForDossier` / `topicDossier` / `topicDossierRows` / `topicDossierExport` / `topicDossierSelfCheck`；引用集**由本机摘录现装配**（不另建一份专题库 —— 那会是第二个真源）。
- 【视图跨书专题夹区块】面读数 / 三栏行 / 导出成稿 / 清空勾选（**只清选择，不动摘录**）。
- 【与上一版的接续：R5-X8 的「单次 vs 整系列」分形 + R5-O9 的「唯一出处」纪律】计划原文写的是「O7/O8/O1，M5-X9；跨书研究能力与性能修复分别验收」——本版把它真正复用起来，不是另起一套：本件的「**单条引用**可回源 / 失效」与 R5-X8 的「**单次例外**只动那一期」同规（都是**把「这一条」与「整批」分开**：前者不许因一条失效而丢掉整份清单，后者不许因改一期而动了全系列）；而「导出带书名/章节/版本/定位」与 R5-O9 的时间方向三态同规（**唯一出处**：四样出处只在契约件一处拼，视图不自己拼那一行）。R5-O9 那两处形态（唯一出处、不认识不许兜底）在本版各有一处同族落点（`dossierRows` 唯一出处、不认识的栏名归原句栏）。
- 【本版自己抓到的真缺陷（当场修）】`dossierRefs` 首版把「取书目」与「装配引用」放在同一个 `try` 里 ⇒ **一次取书失败会让整份引用集消失**（返回空数组），而那正是本项要治的「引文静默消失」。修法：书目单独取一次并包 try，取不到时**照样产出每一条引用**（书名留空 ⇒ 契约件判「回不到原处」）；顺带把循环里的逐条 `getBooks()` 改成一次取 + Map 查表（原写法是 O(n·m) 的取数）。
- 【本版自己抓到的判据缺陷】A2 首版判「全文不得出现 `contentHash`」—— 而它在既有的阅读视图里别处也有，判全文会把既有形态算成本版缺陷；改为只判本版新增的专题夹那一段。
- 【判据 tests/system-v4420.test.mjs 二十一条】六组：口径（面四态与引用五态互不同形、三栏互不相同、纯契约零副作用、视图接线）/ 内核行为（三本书同名不混引、原句与解释分栏、失效照旧列出、改版与书没了分形、未选择的资料不进成稿、导出带四样出处）/ 接线行为（引用集装配 / 勾选 / 清空 / 导出 / 取不到书照样列出 / 视图不直摸契约件）/ 五条定点破坏负控制（各带原版必真的反向对照）/ 版本锚。
- 【不做：不全库上传】导出只含勾过且仍可回源的引用；未选择的资料一条都不进成稿。
- 【不做：不复制整书到上下文】本件只搬**引用条目**（原句片段 + 我的文字），不复制整本正文；书目只带 ID / 书名 / 版本指纹。
- 【不做：不自动认定研究结论为剧情事实】本件不产任何自动结论、置信度或裁决（`DOSSIER_FORBIDDEN_KEYS` 自检真跑）。
- 【看起来没坏但显示不对】本版两处缺陷都不报错、不崩界面，只是「取书失败时引文整份消失」与「既有字符串被算成本版缺陷」。
