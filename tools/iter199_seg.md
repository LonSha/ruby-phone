## 迭代 199 · v4.40.0（2026-02-23）

- 【版本升至 4.40.0（五源同源）：第五期 R5-X5 群聊前的共同往事选择器】关系回忆册与个人视角卡都已存在，但它们回答的是「**甲乙之间**发生过什么」；本项要回答的是**另一问**：「这一屋子人（≥2 位）里，哪几件旧事是所有人都能拿出来说的？」而手机侧全仓零「组级共享可见性」实现：`knowledgeCheck` 判的是**单人**视角（「这条对甲可见吗」）。于是群聊里想提一件旧事时只能凭人脑记「丙不知道这件事」—— 而**加一个人就整个结论作废**这件事在界面上没有任何落点。
- 【契约件新增组级四态 × 单件四态】组级：没有数据源 / 有源但空 / 有可判定旧事 / 读不到。单件：可共享 / 不许说 / 判不了 / 还没选人。压平任意两态都会造出处置相反的处境长得一样。
- 【★「不知情」与「判不了」必须分形（本项核心）】「丙确实不知情」是「别提这件事」；「我们不知道丙知不知道」是「先去问清楚」或「别提，但理由不同」。压成一格会让用户以为系统知道丙不知情，而其实**根本没数据**。故 `undecided` 单列一格；且**知情名单根本没给**时整件判不了（不读成「没人知道」）。
- 【★ 成员指纹：顺序无关，一变就整块作废】`membersKeyOf` 按排序后的成员集合出指纹 —— 顺序无关（否则换个顺序就被误判成「成员变了」，旧预览被误作废）；集合一变则**旧预览整块作废**。
- 【★ 交接闸 handoffGate：成员变了**拦住**】验收原文点名「加入丙后重新移除秘密，**不能沿旧草稿一键误发**」—— 故交接前三态分句：可以交接 / **必须重挑**（成员变了）/ 一件都不能交。且「作废」与「没有可共享的」**不同形**。
- 【不从亲密度推定知情】计划原文「不做：不从亲密度推定群成员知情」—— 本件不产任何亲密度/分数读数（`SHARED_FORBIDDEN_KEYS` 自检真跑）；上游不在场时本机**不推知情**，一律如实报「判不了」。
- 【控制器五口】`sharedPastPack` / `_localSharedPast` / `sharedPastMark` / `sharedPastSetMembers` / `sharedPastContractSelfCheck`；本机降级路径**只列旧事、不填知情名单**（那正是「判不了」的来源）。
- 【视图群聊菜单「共同往事」+ 面板】只在群聊里给；面板分列可共享 / 不许说 / 判不了，并把交接闸的读数摆在显眼处。
- 【与上一版的接续：R5-X4 的「判不了 vs 不知情」分形 + R5-X2 的「两格分列」纪律】计划原文写的是「微信群聊/creationdesk + M5-X5；交接沿 O1」——本版把它真正复用起来，不是另起一套：本件的「不知情 vs 判不了」与 R5-X4 的「未标注不算独立」同规（**判不了就不硬算**）；而「成员指纹」与 R5-X2 目标树的「计划 vs 事实两格」同规（都是**让「变了」这件事可被判出来**）。R5-X4 那两处形态（唯一出处、不硬算）在本版各有一处同族落点（`handoffGate` 唯一出处、本机降级不填知情名单）。
- 【本版自己抓到的判据缺陷】A2 首版判「全文不得出现『不许说』」—— 而它在 18888 行的既有 chat-view 里别处也出现，且我自己面板的说明文字里也有（判全文会把既有形态与说明文字算成本版缺陷）；改为只判本版新增的面板那一段、判的是「面板不得自持单件状态字面量」。
- 【判据 tests/system-v4400.test.mjs 二十条】六组：口径（组级/单件四态互不同形、判定唯一出处、纯契约零副作用、视图接线）/ 内核行为（两人组可共享、加入丙移除秘密、成员变了作废并拦住交接、指纹顺序无关、不知情与判不了分形、三态分形、不产亲密度）/ 接线行为（上游在场 / 上游不在场只判不了 / 取数抛了 / 换会话作废 / 视图不直摸上游）/ 四条定点破坏负控制（各带原版必真的反向对照）/ 版本锚。
- 【不做：不自动群发】本件只出「哪几件能说」的读数与交接闸；发送仍由用户在原聊天里手动完成。
- 【不做：不从亲密度推定群成员知情】同群只证明「都在这群里」，证明不了「都看过这条」—— 故本机降级路径不填知情名单。
- 【看起来没坏但显示不对】本版缺陷不报错、不崩界面，只是「既有字符串被算成本版缺陷」。
- 【运行时验证边界】本版未做浏览器/真宿主取证。「交给原聊天草稿」属**真 DOM 层 + O1 交接面**读数；本版判的是它的可判定前件（`handoffGate` 在成员变更时必须拦住）。docs/runtime-verification-boundary.md 的当版实测数字由 tools/refresh_doc_readings.py 现场跑两道门写入。
