- 【读不出与空台账分两句，两条链同口径】四类读失败各自点名（无存储 / 读抛错 / 坏 JSON / 可读但零条），前三类拒收且不改盘，第四类才当「还没拍过 / 还没编过」处理。这条在两条链上都配了判据：读不出时提交必须走状态不可读这一支，空台账必须能正常收下 —— 两者处置相反，塌成一格就会出现「台账坏了但界面说没编过」。
