- 【本版自己抓到的缺陷形态（三条，都不报错）：一是**基线被候选顶掉** —— 已应用版本当时就是 base 与 parsed 这两个字段本身，选一份新文件的那一刻基线就没了，对账于是拿候选与自己比，读数恒为「全部同值」，界面写着「什么都没变」而用户手上明明是一份改过的资料；二是**窗口读的移除清单被当成真清单** —— 逐段读下一段时窗口外的段不是被删了，只是这一次没读到，按它删东西就会真删；三是**只剩引用被压成没有应用过** —— 重开后存储里只有一把引用（本版刻意不复制全文），界面却写「没有已应用版本可作基线」，而它上一行刚写过「已应用 a.txt（只剩引用）」，同一块读数自相矛盾】
- 【config/lore-import-contract.js 新增 loreVersionRef：一份已解析资料的**版本引用**，纯算术（无随机、无时钟、无存储），产出文件名 + 字符数 + 段数 + 一把由 文件名 与 字符数 与 每段键与指纹 复算出的键。同一份重读一次键不变，改一个字键就变；**刻意不带正文也不带段标题清单** —— 计划原文的不做条款写着不默认永久复制两个全文到 PhoneStorage，只保存版本引用】
